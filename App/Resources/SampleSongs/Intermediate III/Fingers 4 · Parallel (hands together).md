# Same notes, different fingers

Now both hands play the **same note names**, an octave apart, so they move in the **same direction**.
The finger numbers are different: when the right hand plays 1, the left hand plays 5.

```staff
right: C4/1 D4/2 E4/3! F4/4 G4/5 F4/4 E4/3! D4/2
left: C3/5 D3/4 E3/3! F3/2 G3/1 F3/2 E3/3! D3/4
caption: Both hands go up and down together. Only E (blue) uses the same finger, 3, in both hands.
```

## Pay attention to
- Left finger = **6 − right finger**: 1 ↔ 5, 2 ↔ 4, 3 ↔ 3.
- Read the **notes** this time, not just the numbers: both staves show the same shape.
- Go slowly. This is the hardest drill because each hand uses a different finger.

## Learn
Most music has the hands moving in parallel, so this drill trains real independence between the hands.
