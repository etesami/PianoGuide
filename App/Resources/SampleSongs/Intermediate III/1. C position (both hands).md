# Finger numbers mirror in the left hand

The left hand also plays C to G, an octave lower. Finger numbers start at the **thumb in both hands**,
so in the left hand **5 = C** and 1 = G.

```staff
right: C4/1 D4/2 E4/3 D4/2 r:4 C4/1 E4/3 G4/5 E4/3 C4/1:4!
left: r:4 C3/5 D3/4 E3/3 D3/4 r:4 C3/5:4!
caption: The hands take turns. Going up, the left hand counts 5-4-3. Blue: both hands together on C.
```

## Pay attention to
- Going **up** the keyboard, the right hand counts 1 → 5 but the left hand counts **5 → 1**.
- In bar 7 both hands go **down together** on the same notes, with different fingers:

```staff
right: G4/5 E4/3 D4/2 C4/1
left: G3/1 E3/3 D3/4 C3/5
caption: Same notes an octave apart: right 5-3-2-1, left 1-3-4-5.
```

## Learn
Left-hand notes are on the **bass staff** (bottom). C3 is the second space, G3 the fourth space.
