# Repeated notes and held notes

The right hand plays the tune; the left hand plays one long note per bar.

```staff
right: C4/1 C4/1! G4/4 G4/4! A4/5 A4/5! G4/4:2
left: C3:4 F3:4
caption: Repeated notes (blue): let the key come up a little, then play it again with the same finger.
```

## Pay attention to
- **Repeated notes** (C C, G G, A A): the second one must sound again. Don't slide to another finger.
- **The half notes** at the end of each phrase last **2 beats**. Hold them; don't rush to the next note.
- **The left hand holds** its note through the whole bar while the right hand moves.

```staff
right: F4/4 F4/4 E4/3 E4/3 D4/2 D4/2 C4/1:2!
left: C3:4 G2:4
caption: The last C (blue) is a half note (hollow head): count "1 2" while you hold it.
```
